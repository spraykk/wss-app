개인정보 처리방침 — 보행안전 WSS (Walking Safety Score)

최종 업데이트: 2026-01-01 (앱 버전 1.0.0)

보행안전 WSS(이하 "앱")는 걷는 동안 사고다발구역 진입을 감지해 경고하는 안전 보조 앱입니다. 이 처리방침은 앱이 어떤 정보를 사용하고, 어디에 저장하며, 무엇을 전송하는지 정직하게 설명합니다.

요약

  • 앱은 위치, 동작(모션), 오디오 출력 상태를 경고 목적에만 사용합니다.
  • 위치·경로·모션·오디오 상태는 기기 안(온디바이스, AsyncStorage)에만 저장되며 서버로 전송하지 않습니다.
  • 앱은 통계 목적으로 익명 점수(0~100)와 날짜, 그리고 기기별 무작위 식별자(익명)만 통계 서버(Supabase)로 전송합니다. 위치·경로·개인 식별 정보는 전송하지 않습니다.
  • 앱은 개인 위치 이력을 서버로 전송·수집·판매하지 않습니다.
  • 외부 통신은 날씨 조회, 사고다발구역 데이터 조회, 그리고 익명 점수 통계에 한정됩니다.
  • 계정 로그인, 회원가입, 광고 추적 식별자 사용이 없습니다.

1. 수집·사용하는 정보

1.1 위치 정보 (When-In-Use 및 Always)

  • 목적: 현재 위치가 사고다발구역에 진입했는지 판단해 경고하기 위해.
  • Always(항상) 권한 사용 이유: 화면이 꺼져 있거나 앱이 백그라운드에 있을 때도 구역 진입을 감지하기 위해. 백그라운드 위치는 오직 구역 진입 감지·경고에만 사용됩니다.
  • 저장·전송: 진행 중인 보행 세션의 경로 세그먼트와 위치는 기기 내 저장소(AsyncStorage)에만 저장되며 원격 서버로 전송되지 않습니다. 보행이 끝나면 계산된 점수(0~100)와 날짜만 익명으로 통계 서버에 전송될 수 있습니다(2절 참조). 위치·경로 자체는 전송되지 않습니다.

1.2 동작(모션) 센서

  • 목적: 사용자가 실제로 걷고 있는지 판단해, 정지 상태에서 불필요한 경고를 줄이기 위해.
  • 저장: 실시간 판단에만 사용하며 원격 전송하지 않습니다.

1.3 오디오 출력 상태

  • 무엇을 감지하는가: (1) 현재 오디오 출력 경로가 블루투스 이어폰인지, (2) 다른 앱이 오디오를 재생 중인지. 두 신호가 모두 참일 때 "주변음 인지가 어려운 상태"로 간주해 위험 가중치를 높입니다.
  • 무엇을 감지하지 않는가(중요): 앱은 노이즈 캔슬링(ANC) 활성 여부를 감지하지 않습니다. iOS는 이를 서드파티 앱에 노출하는 공개 API를 제공하지 않습니다. 또한 앱은 카메라나 시선을 사용해 "화면을 보며 걷는지"를 감지하지 않습니다. 앱은 오디오 내용을 듣거나 기록하지 않으며, 마이크로 주변 소리를 녹음하지 않습니다. 오직 시스템이 알려주는 출력 경로/재생 여부 신호만 읽습니다.
  • 저장: 실시간 위험 가중치 계산에만 사용합니다.

2. 외부로 나가는 통신 (제3자 데이터 처리)

  • 날씨 조회: 강수/노면 위험 가중치 계산을 위해 대략적 위치로 날씨를 조회합니다. 개인 식별 정보는 포함되지 않습니다.
  • 사고다발구역 데이터: 공공 데이터(사고다발지역 API)로부터 구역 목록을 내려받습니다. 사용자의 위치를 업로드하지 않습니다.
  • 익명 점수 통계 (Supabase): 다른 사용자와 비교할 수 있는 평균·상위 25%(Q3) 통계를 제공하기 위해, 보행이 끝나면 익명 기기 식별자(무작위 UUID), 표시 점수(0~100), 날짜(yyyy-mm-dd)의 세 가지 최소 정보만 통계 서버로 전송합니다. 위치·경로·모션·오디오 상태·원점수(rawScore)는 전송하지 않습니다. 서버는 개별 점수를 다시 조회할 수 없도록 설정되어 있으며, 전체 사용자의 집계 통계(표본수·평균·Q3)만 앱으로 돌려줍니다.

앱은 위 목적 외에 사용자의 위치·모션·오디오 상태 데이터를 제3자에게 제공하지 않습니다.

3. 데이터 보존

  • 보행 세션 결과(WSS 이력)는 사용자가 앱을 삭제하거나 이력을 지울 때까지 기기 내에 보관됩니다.
  • 앱을 삭제하면 기기 내 저장된 모든 데이터가 함께 삭제됩니다.
  • 통계 서버(Supabase)에는 익명 점수·날짜·익명 기기 식별자만 보관되며, 개인을 특정할 수 없고 통계 산출 용도로만 사용됩니다. 앱을 삭제하면 새 익명 식별자가 생성되므로 이전 기기와의 연결은 끊어집니다.

4. 아동 개인정보

앱은 아동을 대상으로 하지 않으며, 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

5. 권한 변경

iOS 설정 앱에서 위치·알림 권한을 언제든지 변경할 수 있습니다. 권한을 거부하거나 축소해도 앱은 기능이 제한된 상태로 동작합니다.
