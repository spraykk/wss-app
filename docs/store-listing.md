```
이 앱은 사고다발구역 진입을 감지해 경고하는 안전 앱입니다.

[백그라운드 위치 사용 이유]
UIBackgroundModes: location. 화면이 꺼져 있거나 백그라운드일 때도 위험구역 진입을 감지해 경고하기 위해 Always 위치 권한을 사용합니다. 위치 데이터는 기기 내에서만 사용하며 서버로 전송하지 않습니다.

[오디오 인식 관련]
블루투스 출력 경로 연결과 다른 앱 오디오 재생 여부(AVAudioSession.currentRoute / isOtherAudioPlaying)만 읽어 위험 가중치를 조정합니다. 마이크 녹음이나 오디오 내용 접근은 없습니다. 노이즈 캔슬링 감지나 카메라 기반 기능은 제공하지 않습니다.

[백그라운드 오디오 모드 미사용]
UIBackgroundModes 에 audio 는 포함하지 않았습니다. 앱은 백그라운드에서 오디오를 재생·녹음하지 않으며, 오디오 상태는 포그라운드/이벤트 시점에만 읽습니다.

테스트: 온보딩에서 When-In-Use 위치를 먼저 요청하고, 이후 맥락에서 Always 및 알림 권한을 요청합니다.
```

## 백그라운드 모드 결정 근거 (FEAT-006 Step 2)

- **UIBackgroundModes = ["location"]** 로 유지합니다. `audio` 는 추가하지 않았습니다.
- 근거: 오디오 감지(`AVAudioSession.isOtherAudioPlaying` / 출력 경로)는 경고 판단을 위해 **읽기만** 하며, 앱은 백그라운드에서 오디오를 **재생하거나 녹음하지 않습니다.** 백그라운드 오디오 세션 유지가 필요한 사용 사례가 없으므로 `audio` 백그라운드 모드는 정당화되지 않으며, 불필요한 백그라운드 모드는 App Review 거부 위험을 높입니다.
- 위치는 백그라운드 지오펜스/구역 진입 감지에 실제로 필요하므로 `location` 만 선언합니다.
